## 摘要
将搜索与函数逼近相结合推动了棋类游戏程序的重要进展，使得自我对弈算法比以往任何时候都更具竞争力。然而，基于蒙特卡洛树搜索（MCTS）的最流行方法的计算开销可能相当大。在这项工作中，我们研究了在非平凡、中等规模的游戏（如四子棋、Hex(7x7)和合成游戏）中，更简单的方法是否仍具有竞争力。我们训练了一个最小化的近似值迭代（AVI）自我对弈实现，并使用真实标签预言机进行精确评估。与预期相反，我们的结果展示了AVI的惊人有效性：它学习到的价值函数比AlphaZero学习的更准确，而其单步前瞻贪心策略在显著更低的训练和推理成本下，仍能与基于MCTS的策略竞争。在奥赛罗和围棋(9x9)上的初步实验表明，AVI在更大游戏上训练稳定，并学习到有效的价值函数。这些发现表明，基于MCTS的方法的成功可能掩盖了那些随着现代深度学习工具而变得越来越实用的更简单方法。

## Abstract
Combining search with function approximation has driven major advances in game-playing programs, making self-play algorithms more competitive than ever. Still, the computational overhead of the most popular methods, based on Monte Carlo Tree Search (MCTS), can be substantial. In this work, we investigate whether simpler methods remain competitive in non-trivial, moderately sized games such as Connect Four, Hex(7x7) and synthetic games. We train a minimal self-play implementation of Approximate Value Iteration (AVI) and use ground-truth oracles for exact evaluation. Contrary to expectations, our results demonstrate the surprising effectiveness of AVI: it learns more accurate value functions than those learned by AlphaZero, while its one-step-lookahead greedy policies remain competitive with MCTS-based policies at substantially lower training and inference costs. Preliminary experiments on Othello and Go(9x9) show that AVI trains stably on larger games and learns effective value functions. These findings suggest that the success of MCTS-based methods may have eclipsed simpler approaches that have become increasingly practical with modern deep-learning tools.

## 1. 论文的核心问题与整体含义

- **研究背景**：在双人零和博弈中，AlphaZero 等结合蒙特卡洛树搜索（MCTS）与深度神经网络的自对弈方法已成为主导范式，在围棋、国际象棋、将棋等领域取得了卓越成就。然而，MCTS 在训练与推理阶段都需要大量神经网络的调用，计算开销与工程复杂度均很高。
- **核心问题**：既然价值函数的准确性是决策的基础，我们是否可以绕开复杂的树搜索，直接用更简单的自对弈方法学习精确的价值函数？具体而言，**简化的近似值迭代（AVI）——仅依赖单步 negamax 备份与 ε-greedy 自对弈——是否能在非平凡的中等规模游戏中与基于 MCTS 的 AlphaZero 竞争？**
- **整体含义**：论文通过 oracle 精确评估与大规模游戏实验表明，MCTS 的成功可能“遮蔽”了更简单方法的有效性。直接学习价值函数在现代深度学习工具支持下已变得相当实用，训练与推理可以解耦设计，搜索或许更多是用于分配推理时计算而非学习有用价值的必要条件。

## 2. 提出的方法论

- **问题建模**：采用 negamax 约定（价值始终从当前行棋者视角表示），交替双人零和完美信息游戏的最优价值满足
  V*(s) = maxₐ [R(s,a) − γV*(f(s,a))]，
  对应一步贪心策略为 G(V)(s) ∈ arg maxₐ [R(s,a) − γV(f(s,a))]。
- **Approximate Value Iteration（AVI）核心流程**：在交替双人游戏中通过网络估计当前策略下的后继状态价值，利用单步 negamax 备份（one-step negamax backup）构造目标值，然后通过最小化平方误差来更新价值网络，并在训练中持续进行 ε-greedy 自对弈数据收集。
  - **目标值构造**：固定目标网络参数 θ̄，对每个状态 s 计算 y_θ̄(s) = maxₐ [R(s,a) − γV_θ̄(f(s,a))]。
  - **训练损失**：LAVI(θ) = E[(V_θ(s) − y)²]，即对状态-目标对做回归。
  - **数据收集**：通过 ε-greedy 自对弈在线产生状态-目标对，存入一个循环回放缓冲区（circular replay buffer），混合不同学习阶段的数据；训练过程在数据收集（网络参数冻结）与缓冲区优化之间交替进行。
  - **完整流程（Algorithm 1）**：初始化网络、缓冲区与 N_envs 个并行环境 → 每轮迭代：数据收集（K 步，计算所有动作的 q 值、存储状态-目标对、ε-greedy 执行动作）→ 训练阶段（N_grads 次梯度更新，最小化 MSE）。
- **与 AlphaZero 的差异**：
  - AlphaZero 使用 MCTS 产生的搜索策略作为策略目标，使用完整对弈终局结果作为价值目标；
  - AVI 只用一步 negamax 备份（即直接利用后继状态的价值估计进行自举，不依赖完整对弈结果），也不学习策略网络。
- **AVI 的已知风险**：同时包含函数近似、自举（bootstrapping）、离策略（off-policy）三个要素，即 Sutton 所称的“致命三角”（deadly triad），理论上容易导致数值不稳定或发散——但实验显示此风险并未显现。

## 3. 实验设计

- **数据集与评测场景**：
  - **Connect Four（四子棋）**：6×7 棋盘，约 10¹² 状态，使用 Pons 的完美 α-β 求解器作为 **强 oracle**（不仅返回输赢，还返回最快赢或最慢输的步数，能区分相同理论结果的动作），评估集为均匀采样与 ε-最优两种各 1500 状态，开局集合 406 个（4 手后）。
  - **Hex(7x7)**：约 10²² 状态，使用基于虚拟连接的完美领域求解器 MoHex 作为 **弱 oracle**（仅返回理论输赢，不区分赢/输动作之间的优劣），评估集 445 个均匀采样状态，开局集合 128 个（2 手后，胜负对半）。
  - **F-Games（合成博弈树）**：由 [Boige et al., 2025] 的 F-Games 生成器构造，minimax 值已知，价值 ∈ {−1, 0, 1}，三种结构：深且窄（h=20, b=2）、平衡（h=10, b=5）、浅且宽（h=5, b=20），每种 10 个独立游戏实例，每个实例采样 4096 个状态。
  - **Othello（奥赛罗）**：8×8 棋盘，无精确 oracle。
  - **Go(9x9)**：9×9 围棋，约 81 个初始落子点，无精确 oracle。
  - Othello 和 Go(9x9) 使用 MiniZero 作为外部参考对手（固定 200 MCTS simulations/move）。

- **对比方法**：
  - **AVI**（本文方法，简化的单步 lookahead + ε-greedy）。
  - **AlphaZero**（室内实现，基于 PGX 和 mctx，S ∈ {32, 64, 128, 256, 512} 模拟预算）。
  - **AlphaZero.jl**（外部独立实现，用于校准 Connect Four 上室内 AlphaZero 的强度，非受控对比）。
  - **MiniZero**（外部已有 AlphaZero 实现，用于 Othello/Go 的基准）。
  - **Cross-inference** 诊断配置：使用 AlphaZero/MiniZero 的 MCTS 策略先验，但叶子节点改用 AVI 的价值函数，隔离价值函数质量对搜索的贡献。

- **评估指标（有 oracle 游戏）**：
  - 价值函数误差 MAE = E|V*(s) − V_θ(s)|；
  - 策略遗憾（policy regret）：衡量选取动作与最优动作之间的价值损失；
  - 与完美 oracle 对抗的失误率（error rate），Connect Four 还报告“昏招率”（blunder rate）；
  - 直接对战比分。
- **评估指标（无 oracle 游戏）**：使用平均对局得分（胜 +1/平 0/负 −1），每个开局双方各执一次，得分范围 [−1, 1]。

## 6. 主要结论与发现

- **AVI 训练稳定且价值函数更准确**：在 Connect Four 和 Hex(7x7) 上，AVI 跨越所有 20 个随机种子均平滑收敛，未出现发散。MAE 始终低于所有 AlphaZero 预算配置（含 S=512），且差距随训练逐步扩大。
- **一步贪心策略具备竞争力**：在 Connect Four 上，greedy AVI 的策略遗憾和失误率接近最强 AlphaZero 配置；在 Hex(7x7) 上，其遗憾与失误率低于所有 AlphaZero 预算。正面对战中，AVI vs AlphaZero(S=512) 在 Connect Four 得分 −0.09 ± 0.04（略逊），在 Hex(7x7) 得分 0.38 ± 0.09（明显胜出）。
- **计算成本优势显著**：最强 AlphaZero 每个决策需数百次（最高 512 次）网络评估，而 AVI 仅需一步 lookahead（Connect Four 至多 7 次、Hex(7x7) 至多 49 次），训练时不需要 MCTS 的树构建/扩展成本。
- **AVI 价值函数为更深搜索提供更强引导**：
  - **Cross-inference 实验**：固定 AlphaZero 策略，在 MCTS 中把叶子节点的价值估计替换为 AVI 的价值函数，在 Connect Four 和 Hex(7x7) 的各个模拟预算下均降低了失误率；
  - **Value-only minimax**：仅用价值函数的更深 minimax lookahead 下 AVI 也更强；
  - 说明 MCTS 的优势更多体现在“把价值转化为决策”的推理时算力分配，而非“学习价值”本身。
- **更大规模游戏上的可扩展性**：在 Othello 和 Go(9x9) 上 AVI 依旧稳定训练；greedy AVI 弱于 MiniZero 的 200 模拟 MCTS（显示贪心策略在大动作空间中的局限），但 cross-inference（MiniZero 策略 + AVI 价值 + 200 模拟搜索）在两种游戏中均**超过原生 MiniZero**，表明 AVI 学到的价值函数可直接提升已有搜索 agent 的棋力。
- **偏见抵消假说**：在交替博弈的 negamax 备份中，后继状态价值以相反符号进入当前价值，一方对价值的过估在上一层会变为欠估，从而使误差在相邻层级之间交替抵消，这可能解释了“致命三角”在交替游戏中并未导致发散。这是一个仍待严格验证的机制假说。

## 7. 优点与亮点

- **评估方式新颖严谨**：在纯神经网络自对弈算法对比中有 oracle 支持的、系统性量化——同时报告价值误差、策略遗憾与完美对手失误率，避免相对 Elo 评分的模糊性，能定位算法短板是在“价值不准”还是“决策转化低效”。
- **极简设计**：AVI 仅需 ε-greedy 自对弈、单步 negamax 备份与一个价值网络，不依赖策略网络、MCTS、复杂超参数，实现了极低计算复杂度下的高水平效果，具有高度的可复现性和工程简洁性。
- **受控公平对比**：室内 AlphaZero 与 AVI 在相同的框架（JAX/PGX/mctx）内实现，共享环境、缓冲区与骨干结构，将差异局限在算法本质（值目标形式、是否使用 MCTS）上。
- **跨域验证**：覆盖有/无 oracle 的多种游戏类型（连接游戏、合成博弈树、回合制棋类游戏），从 10¹² 到 10²² 状态空间，测试了方法的泛化能力。
- **诊断性实验设计**：cross-inference 实验巧妙地将“策略引导”与“价值引导”分离，为 MCTS 组件的作用提供了因果性解释。
- **对大模型/大搜索社区的启示**：证明 MCTS 在学习价值中并非必需品，为未来开发更省算力的自对弈算法打开新方向。

## 8. 不足与局限

- **精确评估所用游戏有限**：核心结论依赖 Connect Four 和 Hex(7x7)（后者是 7×7 规模）及合成 F-Games；这些游戏的复杂度仍低于围棋(19×19)和国际象棋等大规模棋类。
- **Othello/Go(9x9) 缺乏绝对基准**：仅对比固定的 MiniZero 参考 agent，不能量化所训练 agent 离最优/期望水平还有多远；使用不同参考对手或更强 MCTS 预算的结果可能不同。
- **贪心推理的局限明显**：在大动作空间（Go 等）中，greedy 对全部合法动作做无差别单步评估，无法在关键行上加深搜索，实战明显弱于 MiniZero 的 MCTS。作者提出 DAVI（Doubly-Asynchronous Value Iteration）式动作采样或学习策略先验作为改进方向，但论文中未实现验证。
- **计算成本代理措施并不完全**：前向等价网络调用数未计入树构建/填充、磁盘读写、并行调度等开销；只能说近似捕捉主要算力差异，不代表端到端运行时间。
- **超参数敏感性未充分探索**：主要调节了 AVI 的 ε 与 AlphaZero 的 cpuct，对网络深度、宽度、缓冲区大小、梯度步数等没有全面的消融研究，结论对这些设置的稳定性需要更多证据。
- **无更大规模游戏演示**：没有实验表明 AVI 可扩展到 19×19 围棋/国际象棋的规模，而这些恰是 AlphaZero 最著名的主场。
- **“致命三角”稳定性缺乏理论保证**：实验稳定与交替结构解释仍是经验性假设，缺少误差传播的严格理论分析（bound），其普遍适用性尚待证明。
- **弱 oracle 的限制对评估的影响**：在 Hex(7x7) 中，oracle 将所有输（或赢）动作视为等价，因此 Hex 上的 regret 与误差率会抑制完美 agent 与次优 agent 间的差距，使 AVI 的优势可能被低估（但对 AVI 反而更严苛——完美选择与随意输棋动作被同样计分）。
